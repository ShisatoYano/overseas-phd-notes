# 研究テーマ候補

## 方針

フルリモートでのPhD実現を前提に、実機検証を伴わない(シミュレーション・アルゴリズム中心の)テーマを優先する。

【2026-09-26 追加】テーマ選定の必須条件として、次の2点を加える(経緯は `misc/remote-phd-feasibility.md` 追記4)。

- **勤務先のリソースを使わずに完結すること。** 勤務先の設備・コード・開発環境は研究に使わないと合意している。使えるのは個人の計算環境、公開シミュレータ、公開データセット、自作OSSだけ
- **勤務先の非公開情報に依存しないこと。** PhD では成果を論文として公開する必要がある。業務で扱う車両のパラメータや社内データでしか検証できないテーマは、公開できずに詰まる

## 興味のある領域

- 経路計画(Path Planning)
- 制御(Control)
- そのためのモデル推定(State Estimation / System Identification)
- 複数台ロボット・モビリティの協調制御(Multi-Robot / Multi-Agent Cooperative Control)
  - フォーメーション制御、分散制御、プラトーニングなど。単体の経路計画・制御の延長として位置づけられ、複数エージェント間の通信・合意形成もシミュレーション上で扱いやすい
  - 実機での隊列走行等と異なり、シミュレータ上でのマルチエージェント検証で研究を進めやすく、リモート適性は高いと考えられる

これらは `AutonomousVehicleControlBeginnersGuide` (自身のOSS) の延長として位置づけやすく、応募書類上のストーリーも作りやすい。

## 【2026-10-04 決定】研究対象の範囲: 手法を軸にし、対象は大学に合わせる

### 決定

**研究の軸は手法(経路計画・制御・状態推定・マルチエージェントの協調)に置き、適用する対象(自動車・移動ロボット・船舶)は問わない。** 研究提案書は手法の部分を共通にし、最初の研究テーマの対象だけを大学の受け入れ先に合わせて書き分ける(例: TU/e なら自動車、NTNU・MUN なら船舶)。

### 検討した選択肢

| 範囲 | 合う候補 | 判断 |
|---|---|---|
| A. 自動車に絞る | TU/e・Aalto・York・TU Delft | 学費が安いのは TU/e と Aalto だけ。勤務先の業務と近く、非公開情報との切り分けが難しくなる |
| B. 地上の自律移動全般 | A + Twente・TU Delft CoR | 船舶系の大学が外れる |
| **C. 手法を軸に、対象は問わない** | 第1陣・第2陣の10校すべて | **採用** |
| D. 船舶に寄せる | NTNU・MUN・Plymouth・Flinders など | OSS との連続性が弱く、博士課程後のキャリアも業務から離れる |

### C を選んだ理由

- 興味の軸は、もともと手法で決まっている。経路計画・制御・状態推定は、対象が車でも船でも同じ枠組みで扱える(船の運動モデルは Fossen らの公開シミュレータなどで扱える)
- 学費と制度で残った候補(`labs/_candidates.md` Tier S・A)の半分以上が船舶・海洋系。対象を絞ると、選べる大学が大きく減る
- 船舶を対象にすれば勤務先の業務から離れるので、成果を公開するときの制約(上の必須条件)がほとんどなくなる

### 残る課題

- 応募書類で「なぜ船舶なのか」を説明する筋道を作る(船舶系の大学に出す場合)
- 両方に使える共通の研究の軸を決める(例: 不確かさを考慮した経路計画と制御、マルチエージェントの協調)。指導教員候補の研究を見てから詰める(`misc/todo.md` 2-2)
- 船の運動(流体力・外乱)は一から学ぶことになる

## 検討した他の候補領域(参考)

| 領域 | 内容 | リモート適性 |
|---|---|---|
| 知覚・認識アルゴリズム | 公開データセット(KITTI, nuScenes, Waymo Open Dataset)を使った物体検出・SLAM・センサフュージョン | 高 |
| 予測・意思決定 | 軌道予測、POMDP・ゲーム理論に基づく行動決定、マルチエージェント交通シミュレーション | 高 |
| 安全性の形式検証 | 自律システムの形式手法による安全性保証・モデル検査 | 高 |
| Sim-to-Real / 強化学習 | シミュレーション上での方策学習(実機転移は将来課題として切り離す) | 中〜高 |
